# Omur

## Описание
Backend API для проекта по ТЗ Omur. 'Реализован функционал Бесплатная онлайн-консультация специалиста
Получите бесплатную онлайн-консультацию специалиста медицинского центра. Наши врачи помогут разобраться в симптомах, дадут рекомендации и подскажут дальнейшие шаги.
Вы можете позвонить по указанному номеру телефона или сразу написать нам в WhatsApp для быстрого получения консультации.
Нажмите кнопку «Бесплатная онлайн-консультация специалиста» и получите помощь уже сейчас.'


## Стек
Python 3.11, Django 4.2, DRF, PostgreSQL 15

## Быстрый запуск через Docker
1. Создать .env файл по примеру .env.example  
2. API доступно: http://localhost:8000/api/services/ 
3. Админка: http://localhost:8000/admin/

## Локальный запуск без Docker
1. pip install -r requirements.txt  
2. python manage.py migrate  
3. python manage.py runserver
